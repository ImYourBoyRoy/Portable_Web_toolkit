# Portable Web Toolkit v0.3.0

This release establishes a portable, versioned skill pack for toolkit-managed
Astro + Cloudflare projects.

## Highlights

- Six governed skills: four stable core skills, one stable optional skill, and
  one experimental optional Vectorize skill.
- Agent-driven, transactional skill installation guidance for Codex, Cursor,
  Claude, and Antigravity. Helper scripts report status and do not silently
  overwrite installed skills.
- A compact toolkit router, repository-first instruction precedence, portable
  activation fixtures, and per-skill content hashes.
- MIT licensing throughout the repository and toolkit subpackages.
- Release metadata, governance, privacy, syntax, and dependency validation in a
  pinned GitHub Actions workflow.
- Correct update-version direction and reserved example-domain handling in
  privacy scans.

Installed skill copies are not changed automatically. Agents should compare the
manifest with a selected client's current installation before applying an
explicitly approved update.
