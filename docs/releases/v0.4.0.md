# Portable Web Toolkit v0.4.0

Automatic freshness, live WCAGate integration, and standards-aware public
discovery validation for toolkit-managed Astro + Cloudflare sites.

## Highlights

- **Automatic toolkit freshness**: normal toolkit entrypoints perform a
  throttled update check, fast-forward only a clean public `main` checkout,
  refresh the unpinned WCAGate `main` dependency, and report skipped/error
  states without overwriting local work.
- **Live WCAGate bridge**: the website accessibility wrapper resolves the
  current `@imyourboyroy/wcagate` engine from the toolkit dependency instead of
  maintaining a bundled copy.
- **Standards-aware Discovery Doctor**: bounded sitemap XML, robots, llms,
  humans, security.txt, JSON-LD, content-type, REST, and public MCP discovery
  validation with same-origin and response-size safety bounds.
- **Production discovery contract**: `llms.txt`, `llms-full.txt`,
  `humans.txt`, `security.txt`, structured content, headers, and homepage
  JSON-LD are required by default. Profiles can explicitly relax or extend the
  contract; preview/development mode does not require production-only
  sitemap/security.txt artifacts.
- **Wix sourcing doctor**: profile-driven public storefront HTML and JSON-LD
  harvesting without admin credentials or OAuth.
