# Portable Web Toolkit v0.3.2

This release introduces the **Dynamic Symlinked Skill Architecture** for zero-context-bloat skill distribution across all AI coding tools (**Antigravity, Cursor, Claude Code, Codex, Copilot**).

## Key Highlights

- **`portable-web-toolkit-router` Minimalist Skill**: Installed globally (~60 tokens idle cost) to dynamically inspect project needs and link required skills into `.agents/skills/`.
- **`manage-project-skills.mjs`**: Cross-platform manager utility for creating POSIX symlinks / Windows junctions in project scope with `--auto` optional skill detection.
- **Fast-Lookup `SKILL_INDEX.md`**: Selection matrix in `docs/agent-skills/SKILL_INDEX.md` for instant model routing.
- **Scaffolding & Audit Integration**: Automatic skill symlinking in `project-init apply-safe` and `.agents/skills/` health auditing in `site-readiness`.
- **Full Verification**: 100% pass across release validation, skill governance, privacy scans, and unit tests.
