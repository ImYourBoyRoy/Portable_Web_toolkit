# Portable Web Toolkit v0.3.6

Checkpoint-driven staged agent onboarding for non-experts (host → Cloudflare → first site).

## Highlights

- **`docs/agent-skills/ONBOARDING_STAGES.md`**: S0–S9 protocol with stop-and-ask checkpoints (sandbox, host bootstrap, skills, CF token, MCP plugin, site intent, scaffold, brand/secrets, local gates, staging→prod).
- **`site-onboarding` skill** (core, not default-install): thin loader for the stages doc; router sends “new machine / Cloudflare beginner” here.
- README paste prompt + `getting-started.md` lead with staged onboarding.
- **cf-agent** `REQUIRED_PERMISSION_NAMES` adds API Tokens Write, Account API Tokens Write, and Gateway Write; token recipe in cf-agent README.
- **Bootstrap**: after installing desired Python, also runs `pyenv global <desired>` (posix + Windows).

## Operator notes

```bash
# Guided first site
node ./scripts/manage-project-skills.mjs link --project /path/to/site \
  --skills site-onboarding,portable-web-toolkit,site-readiness,site-starter,toolkit-update
```
