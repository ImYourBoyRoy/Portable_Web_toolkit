# Portable Web Toolkit v0.3.3

Hard-segregates accessibility evidence into a standalone package and refreshes toolchain floors.

## Key Highlights

- **WCAG Auditor bridge only**: `Web_Toolkit/wcag_auditor` is a thin site-profile/Astro bridge. The evidence engine lives at `AI/wcag-auditor` (`@roydawsoniv/wcag-auditor`) for websites **and** apps.
- **Site-doctor opt-in**: `--wcag` / `diagnostics.wcagAuditor.enabled`.
- **Toolchain floors**: Astro `^7.1.6`, Cloudflare adapter `^14.1.7`, Wrangler `^4.118.0`, Vite `^8.2.0`, Playwright `^1.62.1`, Node `.node-version` `26.6.0`.
- **Skill architecture unchanged**: global idle cost stays on `portable-web-toolkit-router`; heavy skills remain project-scoped symlinks.

## Upgrade notes

1. Pull / install this release.
2. Ensure the standalone checkout exists at `../../wcag-auditor` (from this repo) or set `WCAG_AUDITOR_ROOT`.
3. Keep only `portable-web-toolkit-router` in global skill homes; link project skills with `manage-project-skills.mjs`.
