# Portable Web Toolkit v0.5.1

Patch release: CI and starter fixes after v0.5.0.

## Fixes

- **CI is green again.** The workflow now installs the WCAGate engine
  (`npm install --prefix Web_Toolkit`) before `npm run validate`. The
  wcag-auditor wrapper tests had only passed because the auto-update preflight
  installed the engine as a side effect, which stopped once `--help` and
  `--apply` invocations skipped the preflight.
- **site-starter `OptimizedPicture.astro`** used shell-style `#` comments in its
  frontmatter, so `astro check` reported 53 errors in every new project. They
  are `//` comments now.

## Validation

- `npm run validate` passes, and the GitHub Validate workflow passes on the
  release commit.

See `CHANGELOG.md` for the complete release history.
