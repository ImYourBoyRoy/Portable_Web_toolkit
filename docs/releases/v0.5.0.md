# Portable Web Toolkit v0.5.0

Agent-ready discovery, cinematic motion primitives, and measurement tools for
toolkit-managed Astro + Cloudflare sites.

## Highlights

- **Agent-readiness checks in Discovery Doctor**: API catalog (RFC 9727),
  Markdown twins, RFC 8288 Link headers, MCP server card, AI crawler policy, and
  sitemap/canonical agreement. Absent surfaces report INFO, so existing sites
  keep their exit codes; profiles can make any surface required.
- **Discovery template v2**: trailing-slash canonical URLs, git-derived dates
  (with an optional import-checkpoint baseline), one JSON-LD `@graph`, AI
  policy, Markdown twins, a whole-site bundle, rate limiting and an optional
  read-only MCP server.
- **preview-check** (new): Lighthouse scores, layout overflow, reduced-motion
  proofs, and a real-background contrast resolver that closes the translucent
  and gradient `cantTell` gap in axe/WCAGate.
- **site-snapshots** (new): reproducible page photographs with drift checks.
- **templates/cinematic**: View Transitions, scroll-driven reveals, a circuit
  canvas and the performance contract that keeps PageSpeed at 100.
- **WCAGate wrapper**: `--base-url` now applies to checked-in config runs.
- **Refreshed defaults**: Node 26.13.0, current Astro, Cloudflare and Wrangler
  pins; `rimraf` and `cross-env` removed from the starters.
- **cache-purge fixes**: Astro Workers `dist/client` detection, batching,
  429 retry, and non-zero exits when nothing can be purged.

## Validation

- `npm run validate` passes: release metadata, skills, full test suite, syntax check, toolkit self-verification, and a release privacy scan with 0 findings.
