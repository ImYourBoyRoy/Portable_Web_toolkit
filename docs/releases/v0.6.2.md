# Portable Web Toolkit v0.6.2

Patch release from the first macOS CI run of v0.6.1.

## Fixed

- `discovery-postbuild.mjs`, `refresh-page-lastmod.mjs` and `sync-fonts.mjs` silently did nothing (exit 0) when run through a symlinked directory, because the entry-script check compared a symlinked path with a resolved one. They now compare real paths.
- Requires WCAGate 2.4.1 or newer for the same class of fix in `wcagate skills link`; the engine range (`#semver:*`) picks it up automatically.

## Known open (Windows leg is reported, not blocking)

- A few tests import bare `d:\` paths instead of `file://` URLs.
- `form-doctor` reports Windows paths with backslashes.
- Some template and stylesheet tests still fail on Windows.
