# Portable Web Toolkit v0.6.1

Site templates, an installer, themes, forms reliability, and safe servers, on pnpm.

## Highlights

- **`site-templates`**: one command installs the layout, analytics consent, contact form (with Turnstile and a
  strict field allowlist), optional `contact-intake`, component CSS, fonts and base config into an Astro + Cloudflare
  site, with prerequisites, CSS imports and next steps. `show <name>` prints a template's contract in ~150 tokens.
  Verified end to end on a real build: `astro check` 0 errors, discovery-doctor, stylesheet-check, form-doctor and the
  WCAGate gate across 3 routes, light/dark, mobile/desktop.
- **`form-doctor`**: finds contact forms that report success when mail was not delivered (static scan plus a local
  probe against a Worker with a broken mail binding).
- **Themes**: `site-theme` extracts a built site into a named theme, applies it to another site, and compares themes.
- **`dev-ports`**: free-port selection and process ownership. The toolkit stops only the servers it started and asks
  before touching anyone else's; `wcag-auditor`, `preview-smoke` and `form-doctor` use it.
- **Peer-aware `package-updater`** with release-age gating, hold explanations, and `migrate` to pnpm.
- **`toolkit-index`** and a generated `docs/TOOLS.md`: which tool for which task in ~2.5k tokens.
- **pnpm everywhere**: the toolkit, WCAGate and CI use pnpm; npm remains a fallback for the engine install.

## Requires

- WCAGate 2.4.0 or newer for the grouped agent report, contrast resolution, the matrix and `autoPort`. The toolkit asks
  for the latest release tag (`#semver:*`), so tag WCAGate 2.4.0 before or with this release.

## Validation

- `pnpm run validate` passes (skills, release, about 520 tests, syntax, toolkit verify, privacy scan).
