# Portable Web Toolkit v0.6.3

Patch release from running the suites on a real Windows Server 2025 guest and a real macOS 26 guest.

- Windows: the listener-ownership check (a foreign server answering on the port we chose) now works; it previously always answered "unknown".

Verified: Linux 537, macOS 537, Windows 535 passing, 0 failing. Requires WCAGate 2.4.2 or newer for the matching Windows fixes (`#semver:*` picks it up).
